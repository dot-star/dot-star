- You mark a todo done, and "done" is the satisfying word, where `Check off` or `Tick` names the checkbox mechanics instead. One fixed form also keeps these commits reading the same in the log.
  - Past todo-tick subjects drifted across `Check off`, `Mark ... done` and `Tick`; naming the rivals lets a reviewer catch the drift by sight. `Mark off` was the first candidate, set aside for `Mark ... done`.

- A subject naming the means hides the reason: `Menlo` reads as taste, so a later reader swaps in another font and reintroduces the jitter the switch fixed. The property is what has to survive, so it's what the log should carry.
